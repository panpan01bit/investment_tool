# 社媒热度 tilt 接入策略 0030：匹配性、接入点与验证协议

> 回答三个问题：社媒热度工具与策略 0030 是否匹配、往哪里加、能改善多少。
> 结论先行：**匹配"主题强度"与"拥挤度风控"两个信号槽；接入点在 `adj_zc`；能改善多少
> 当前无法可信回答——需要按本文协议采集 ≥6 个月数据后用你们自己的 clean ablation 实测。**

## 一、匹配性分析（对照 strategy_0030_spec §二）

| 0030 信号槽 | 匹配度 | 判断依据 |
| --- | --- | --- |
| `λ_theme·theme`（主题项） | **高** | heat 斜率（7日变化）就是"主题关注度强度"的直接度量，且是连续量、可日频更新；0030 已用 p_trend 门控主题项，恰好补上"社媒热度在均值回归市会乱开火"的短板 |
| 龙虎榜 tilt（A股专属） | **中（互补）** | 龙虎榜仅覆盖 A 股（2018 起）；StockTwits/Reddit 散户情绪是 US_CN/US_NC 桶的"散户事件 tilt"类似物——但证据等级远低于龙虎榜（净买额是交易所口径，社媒是注意力口径） |
| 拥挤度熔断（spec §五.5 预留） | **高** | spec 自己提出"小盘池需配套流动性/拥挤度熔断"；heat≥90（白热化）是现成的散户拥挤监测器，方向应是**减仓不加仓**（注意力驱动反转，Da-Engelberg-Gao 2011） |
| 核心因子（低波/价值/质量） | **不匹配** | 慢变量基本面因子 vs 快变量注意力噪音；混入只会稀释 RankIC 加权体系 |
| 宏观 regime 总闸 | **不匹配** | Polymarket 单事件赔率噪音大，不及现有社融/NFCI/信用脉冲体系 |

覆盖面现实：免费源以英文社区为主 → **US_CN / US_NC / 美股桶可用性最好**；
A 股个股在英文社区命中极低（300308 实测 no-results）——A股的散户信号仍应靠龙虎榜，
社媒 tilt 的合理边界是 **美股/中概/港股大市值子集**（占 N=20 中的 12 席）。

## 二、数据现状与采集（必须先做）

社媒数据没有 2005-2026 的长历史可回填（Polymarket 2020 年创立、StockTwits 流更短、
Reddit 搜索对金融帖的时序覆盖不稳定）——**因此无法把社媒项放进 0030 的全量回测**。
唯一诚实路径：从今天起日频采集，攒出自己的历史。

```bash
# crontab（每日 08:30，晨报之后）
30 8 * * * cd /path/to/investlab && .venv/bin/investlab social-record >> data/logs/social.log 2>&1
```

- 落盘：`data/social_history.jsonl`，按 (date, symbol) 去重，断点安全；
- 默认观察集 = 持仓 + 光模块/液冷/HBM/AI芯片代表标的（≤30 只，可 --symbols 覆盖）；
- **≥60 日**后 `investlab social-tilt NVDA` 开始返回数值；**建议 ≥120 日**再进策略实验。

## 三、接入点（paper_trade_0030.py 两处，均为可开关参数）

### 3.1 主题 tilt（替换/并列 λ_theme 项）

```python
# 原（spec §2.4）：
adj_zc = zc + p_trend * (λ_theme*theme + λ_mom*mom_z) + λ_lhb*lhb_z

# 增加社媒项（与 theme 并列做 ablation，或替代 theme）：
tilt = social_tilt_map.get(sym)            # -1~+1，None=覆盖不足
adj_zc += p_trend * λ_social * tilt        # λ_social 起步 0.3（< λ_theme 0.6）
```

- `λ_social` 必须小于 `λ_theme`：社媒信号证据等级低一档；
- 沿用 p_trend 门控：趋势市才让注意力倾斜生效；
- **None 的处理 = 跳过该项**（不是 0 值替代——覆盖不足与中性是两回事）。

### 3.2 拥挤度风控（叠加在 tilt 之上，独立开关 --social-crowding）

```python
if heat >= 90:                       # 白热化
    tilt = 0                         # 不再加仓
    # 可选增强：对小盘池内 heat≥90 的持仓，下周权重 ×0.5
```

### 3.3 备选（不建议首批）：龙虎榜式截面 z

`social_tilt` 做截面 z 分后按 `λ_lhb` 同款方式加入美股桶——但龙虎榜是交易口径、
社媒是注意力口径，证据等级不同，建议放在 3.1/3.2 验证有正贡献之后再试。

## 四、验证协议（沿用 0030 的纪律，一条不减）

1. **clean ablation**：基线 0030 → +social-tilt 单变量；再拆 tilt 水平项/斜率项、
   拥挤度开关各自单测。窗口先用 DEV 2021-2026。
2. **数据窗约束**：社媒历史从采集日开始，前 `min_days` 标 None——意味着首个
   可测窗口至少是采集开始后 3-6 个月。**不要用"历史模拟热度"（用旧帖回填）冒充
   实时信号**：幸存者偏差会让回填结果虚高。
3. **成本口径**：沿用你们的双口径（8bp 粗 + 权重差+12bp 冲击）。社媒 tilt 会增加
   小盘/主题股换手，12bp 口径下净增益为正才有效。
4. **验收建议**：DEV 窗净增益 ≥ +0.5pp 且 Sharpe 不降，才进 OOS；拥挤度开关单独以
   "回撤/回撤持续天数"验收，不以收益验收。

## 五、能改善多少（诚实的量级预期，非承诺）

| 情形 | 年化 | 回撤 | 依据 |
| --- | --- | --- | --- |
| 悲观 | -0.3 ~ +0.5pp | 无改善 | 信号太弱/覆盖不足/换手成本吃掉增益（主题tilt常见结局） |
| 中性 | +0.5 ~ +1.5pp | -0 ~ -2pp | 注意力斜率在趋势市提供增量入场时机；拥挤度退出避开部分散户冲高回落 |
| 乐观 | +1.5 ~ +2.5pp | -2 ~ -4pp | 需同时满足：US_CN 桶占比高、2026-27 主题行情延续、拥挤度退出恰好避开事件顶 |

参照系：0030 自己的 ablation 里，龙虎榜（交易口径事件数据）给了 +7.44pp；
社媒（注意力口径）信息含量理应低一档。**如果 ablation 结果落在"乐观"档之上，
先怀疑过拟合而不是高兴。**
